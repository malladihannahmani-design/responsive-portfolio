# Advanced Responsive Portfolio Website

## 📌 Project Overview

This project is a modern and responsive portfolio website created using HTML, CSS, and JavaScript. It is designed to showcase personal details, skills, projects, and contact information in a professional way.

The website works smoothly on mobile phones, tablets, and desktops using responsive web design techniques.

---

## 🚀 Features

* Fully Responsive Design
* Modern and Colorful UI
* CSS Grid and Flexbox Layout
* Dark/Light Mode Toggle
* Project Section with GitHub Links
* Smooth Hover Effects and Animations
* Contact Form
* Mobile Friendly Design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
